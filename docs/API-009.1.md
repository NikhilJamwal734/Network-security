# API-009.1 — Universal architecture (compatibility foundation)

All files in this package are **new**. Do not replace your working `app/api/main.py`, existing Cisco ASA parser, analyzer, serializers, React components, or any current test.

## Install
Copy the included `app/core` directory under the existing project's `app` directory and copy `tests/test_api_009_1_architecture.py` into the existing `tests` directory. Keep the directory structure.

## Test
From project root:

```powershell
python -m pytest -q tests/test_api_009_1_architecture.py
python -m pytest -q
```

## What changes now
- Adds a trusted, explicit registry for platform adapters.
- Adds identifiers, families, and approved file extensions as immutable metadata.
- Wraps the existing Cisco ASA parse/analyze/report flow without rewriting it.
- Adds compatibility and registry security tests.

## What does NOT change now
- `/api/v1/analyze` remains Cisco ASA only.
- The frontend and upload validation remain exactly as before.
- No automatic platform detection, new vendors, dynamic imports from user input, or alternate file parsers.
- The adapter's `analyze(lines)` is a trusted internal entry point; it expects lines already validated by the existing untrusted-config file reader. It is **not** a replacement for input validation.
